# Algorithm

C++ exercises for the Algorithm course, grouped by technique.

| Folder | Topics |
|--------|--------|
| [BruteForce](BruteForce/) | Brute force, permutations, recursive enumeration |
| [DivideAndConquer](DivideAndConquer/) | Binary search, inversion count, matrix exponentiation |
| [Dynamic](Dynamic/) | Dynamic programming: LCS, knapsack, matrix chain, coin change |
| [Graph](Graph/) | BFS/DFS, connected components, cycles, shortest paths (Dijkstra, Bellman-Ford, Floyd), MST |
| [Greedy](Greedy/) | Fractional knapsack, interval scheduling |
| [SearchSpace](SearchSpace/) | Backtracking and branch & bound: N-Queens, 15-puzzle, knapsack |

Build any single file with:

```
g++ -std=c++17 file.cpp -o file
```
